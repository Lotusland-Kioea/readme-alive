# 审计维度定义

## 通用维度（所有项目类型）

### 🔴 Critical：必须修复

| 维度 | 检查内容 | 判定逻辑 |
|------|----------|----------|
| **依赖版本准确性** | README 声称的依赖版本 vs 构建文件（pom.xml/package.json/go.mod 等）实际版本 | 版本号不匹配即为 Critical |
| **API 端点准确性** | README 列出的 API 端点路径和方法 vs 代码实际路由定义 | 路径或方法不一致即为 Critical |
| **命令可执行性** | README 中的安装/启动/测试命令 | 命令语法明显错误或引用不存在的文件/脚本 |
| **链接有效性** | README 中的内部链接（指向本仓库文件的相对路径） | 链接目标文件不存在即为 Critical |

### 🟡 Warning：应该修复

| 维度 | 检查内容 | 判定逻辑 |
|------|----------|----------|
| **模块覆盖** | 代码中的顶层模块/包目录 vs README 项目结构章节的覆盖 | 代码有但 README 未提及的模块 |
| **依赖覆盖** | 构建文件中的关键依赖 vs README 技术栈表 | 关键依赖（非传递依赖）未在 README 列出 |
| **配置覆盖** | 配置文件中的关键配置项 vs README 配置说明 | 新增 profile/environment 未说明 |
| **README 过短** | README 行数 vs 项目复杂度对应的合理范围下限 | 低于下限 30% 以上 |

### 🔵 Info：改进建议

| 维度 | 检查内容 | 判定逻辑 |
|------|----------|----------|
| **缺少关键章节** | 是否存在"快速开始"、"使用示例"、"许可证"等 | 缺少一个或多个 |
| **内容归属不当** | 是否包含版本变更历史、开发日志、学习笔记等 | 检测到疑似 CHANGELOG/知识库内容 |
| **README 过长** | README 行数 vs 项目复杂度对应的合理范围上限 | 高于上限 50% 以上 |
| **缺少徽章** | 是否包含 CI 状态/许可证/版本徽章 | 不强制，作为建议 |

## 按项目类型的特殊维度

### Web 应用

| 维度 | 严重度 | 说明 |
|------|--------|------|
| 对外接口路径 | 🔴 Critical | API 端点/路由与代码实际路径对比 |
| 接口请求/响应格式 | 🟡 Warning | 参数名、类型是否匹配 |
| 端口/启动配置 | 🟡 Warning | 与实际配置文件对比 |
| 前端路由 | 🟡 Warning | 与前端路由配置对比 |

### CLI 工具

| 维度 | 严重度 | 说明 |
|------|--------|------|
| 子命令列表 | 🔴 Critical | 与实际 CLI 定义对比 |
| 选项/参数 | 🟡 Warning | --flag 是否与实际定义一致 |
| 安装命令 | 🔴 Critical | pip/ npm/ cargo install 等 |
| 使用示例输出 | 🟡 Warning | 示例中的输出是否与当前版本一致 |

### 库/SDK

| 维度 | 严重度 | 说明 |
|------|--------|------|
| 公共导出签名 | 🔴 Critical | 导出的函数/类/方法名是否正确 |
| 安装指令 | 🔴 Critical | 包管理器安装命令是否正确 |
| 最低版本要求 | 🟡 Warning | 语言/运行时版本要求是否准确 |
| 类型定义 | 🟡 Warning | TypeScript 类型/导出是否匹配 |

### Monorepo

| 维度 | 严重度 | 说明 |
|------|--------|------|
| 子包 README | 🟡 Warning | 子包是否有独立 README |
| 子包链接 | 🔴 Critical | 根 README 中的子包链接是否可达 |
| 统一技术栈 | 🔵 Info | 是否声明共享的技术栈和约定 |
| 导航结构 | 🔵 Info | 根 README 是否提供了清晰的子包导航 |
